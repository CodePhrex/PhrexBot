# Security operations

Conversational events require exact workspace and explicit administrator identity. In-process admission suppresses accepted event IDs for ten minutes, limits each user to one accepted request per 15 seconds, caps caches at 4096 entries and limits simultaneous inference to two requests. Missing event IDs fail closed. Audit messages omit question, answer and credentials. These controls reset on restart and are not distributed. Existing slash-command permissions are unchanged; wildcard access exposes configured repository metadata to workspace members and must be reviewed before production. Host and executive commands require explicit administrators. Keep .env outside version control, restrict filesystem ACLs, rotate tokens and use least-privilege scopes. OS credential vault integration, durable audit, slash-command throttling and live security testing remain pending.
