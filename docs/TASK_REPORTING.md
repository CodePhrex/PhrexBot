# Task reporting adapter

Set PHREX_TASK_SNAPSHOT to a local JSON file generated by a trusted reporting process. Format: `{"as_of":"2026-01-01T00:00:00+00:00","tasks":[{"name":"Example","status":"paused"}]}`. This is an illustrative schema, not actual task data. Update atomically, restrict filesystem access, and never include secrets. Reports older than 24 hours are marked stale. No ChatGPT automation API or automatic producer is included. Docker users must mount the snapshot read-only and set the container path.
