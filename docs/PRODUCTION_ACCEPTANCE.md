# Production acceptance

Before deployment run `python -m unittest discover -s tests` in the updated virtual environment. Verify dependency installation and test slash commands, administrator denial, dashboard sources, Slack DM delivery and Ollama separately. Use start-phrex.ps1 from the repository root; it reads local .env without printing credentials. Configure Windows Task Scheduler under the existing user account, at logon, with restart on failure and no parallel instances. Do not elevate privileges. Stop the existing bot before enabling scheduled startup. Verify logs and Slack connectivity; retain prior commit for rollback. Automatic startup is not installed by this commit. Configure explicit administrator IDs, Slack event scopes and local model before conversational activation. Review wildcard slash permissions. Remaining gates include project registry population, evidence orchestration, automatic task snapshots, Slack graphical upload, credential vault and durable audit. Docker host telemetry describes the container environment, not necessarily the Windows host. No production acceptance is claimed by merging this PR.
