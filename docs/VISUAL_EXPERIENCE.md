# PhrexBot Visual Experience v1.0

Approved 2026-11-25. CodePhrex Intelligence — Intelligence on Command.

## Identity
Obsidian #030711; Midnight #081525; Electric Blue #006CFF; Cyber Cyan #00D9FF; Ultraviolet #8B35FF; Platinum #E8F2FF. Use the approved CP hexagonal monogram. Slack native fonts and backgrounds remain client-controlled; custom typography is limited to artwork. Use accessible text alongside graphical indicators.

## Emoji registry
- :phrex-ai: intelligence
- :phrex-online: verified healthy state
- :phrex-build: development and compilation
- :phrex-critical: critical failure
- :phrex-approval: authorization or review request
- :phrex-pending: pending operation
- :phrex-release: release/deployment
- :phrex-secure: security and verification

## Command Intelligence
Authoritative, professional, analytical, concise and evidence-driven. Report scope, source, timestamp, observed state, limitations and actionable next steps. Never equate missing data with healthy status or open PRs with failed builds. Avoid unsupported severity, completion or approval claims. Distinguish snapshots from live telemetry.

## Layout
Use Block Kit header, classification context, divider, project sections, repository links and branded footer. Executive, incident, development, security and help templates. Use native formatting and optional attachment accent colors; no unsupported custom text colors. Preserve private responses, workspace authorization and read-only GitHub access. Escape untrusted text and keep Slack block limits.
