# Navigation engine

Generate GitHub repository, actions, PR, issue, commit, release, security and README links; Slack channel permalinks; administrator-registered HTTPS application links; and Slack Block Kit URL buttons. Exact hostname allowlists, HTTPS only, no credentials in URL, nonstandard ports, control characters or arbitrary URI schemes. Trusted host configuration and app registry must be controlled by administrators, not AI output or Slack users. Links are navigation only: no remote execution or automatic application launch. Destination availability and redirects are not verified. Do not include secrets in URL paths or query strings. Private project links require the same entitlement checks as project data. Integration into live command responses and app registry population remain pending.
