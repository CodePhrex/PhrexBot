# Project knowledge registry

Use `ProjectStore` with a local database path outside the repository. Each profile can contain purpose, architecture, blueprint references, milestones, dependencies, branding and deployment references. Record the source and evidence classification (planned, verified or estimated). The caller is responsible for verifying evidence; a classification is not independent verification. Do not store tokens, credentials or personal data. Profiles are replaced on update, not automatically merged. No Slack command or AI ingestion is enabled by this module. Populate only authorized project records and enforce per-user repository access before exposing them. Future ingestion must treat documents as untrusted data and preserve provenance. No project progress percentages are inferred.
