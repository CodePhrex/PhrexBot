# Conversational intelligence

Optional Ollama adapter uses the fixed loopback endpoint 127.0.0.1:11434 and an explicitly configured installed model. Administrator-only, exact workspace match, bounded question/evidence/output, no redirects, no tool execution. Caller must independently authorize and minimize evidence before invoking; never pass secrets, raw environment variables or unrestricted file contents. Model output is untrusted plain text, not commands or verified facts. Prompt instructions do not guarantee resistance to injection or hallucinations. Render output safely without automatic mentions, links or actions. Local Ollama installation and model selection are not performed by this module. Cloud providers, evidence retrieval orchestration, Slack events and live inference tests remain pending. Do not expose the Ollama endpoint publicly.
